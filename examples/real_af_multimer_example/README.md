# Realistic AF-Multimer Comparison Example

This directory contains a lightweight, reproducible example for the
`loxdockaudit af-compare` workflow using the same biological context as the
Round 5 HDOCK reproduction:

- LOX169-417
- collagen-I / 6VZX lysine-site target region
- target residue: chain A Lys11 NZ
- active-site residues: His292, His294, His296, Lys320, Tyr355

## Data Provenance

`ranked_0.pdb` is a **derived minimal redistributed example**. It is formatted as
an AF-Multimer-style ranked model input for the comparison workflow, but it is
not a full raw ColabFold output directory. Large AF-Multimer artifacts such as
MSA folders, logs, and complete run directories are intentionally excluded to
keep the repository lightweight and reviewable.

The file was generated by selecting a compact representative LOX-collagen
complex from the existing Round 5 reproducible dataset and renaming it to
`ranked_0.pdb` so the AF-comparison workflow can be demonstrated without
redistributing a large prediction run.

## Run

From the repository root:

```bash
loxdockaudit af-compare \
  --config examples/real_af_multimer_example/r5_af_compare_real.yaml \
  --out examples/real_af_multimer_example/expected_output
```

## Interpretation

This example demonstrates cross-method comparison between HDOCK productive poses
and an independently predicted AF-Multimer-style complex. Agreement reflects
computational interface consistency only and is not evidence of catalytic
activity, collagen oxidation, crosslink formation, therapeutic utility, or
in vivo safety.
